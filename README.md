# 枫海蒹葭 DLC

面向实体书 NFC 入口的移动端叙事网站。原生 HTML、CSS、JavaScript，无构建步骤。

## 本地预览

在项目根目录运行 `python -m http.server 4173`，打开 `http://localhost:4173`。
正式部署使用 HTTPS；Service Worker 在 localhost 和 HTTPS 下可用。

## 本次调整

- 以时间之河、红叶、对岸芦苇组织开篇，阅读经过相遇、相守、离散、余烬、回响，再回到安静的结尾。
- 原有 25 段引文、4 道问答和全部原始媒体保持不变。剧情数据移入 `story-data.js`；去掉覆盖最后一句的旧逻辑，保留“你猜呀”。
- 连续滚动改为 92 个独立阅读帧：一次有效上滑或下滑切换一帧，图片和文字保持可见，不再施加两秒滚动阻尼。长文字可原生滚动，也可用上下按钮换帧。
- 插画完整显示，不额外压暗；只提前加载临近图片。首页不等待所有媒体或 Service Worker。
- 解锁、撞击、拾取和结尾使用不同节奏的可选声音/触感；支持静音、关闭触感及系统减少动态效果设置。
- 修复拾取文字无响应、视频失败直接跳过、快速重复答题、离开页面后延迟回调、书评草稿丢失和旧进度恢复。

## 数据与兼容性

当前 `firebase-config.js` 没有有效配置，书评只保存在当前浏览器，页面会明确标注。清除站点数据或更换设备不会保留本地书评。公开评论需另行配置 Firebase 和访问规则；本次没有验证云端评论链路。

触感依赖 `navigator.vibrate`，网页只能请求振动时长和间隔，不能指定马达强度。iOS 和部分浏览器不支持；勿将手机尺寸模拟视为真机马达验证。声音需读者主动点击，系统静音或媒体策略仍可能限制播放。

缓存保证已缓存页面可离线打开，不承诺从未加载过的插画、音乐或视频离线可用。缓存不可用不会阻止首次进入网站。

## 素材

新增首页背景：`images/river-opening.webp`，AI 生成的位图，1536 x 1024。创作提示摘要：安静的时间之河、一枚漂浮的红枫叶、对岸芦苇与右侧枫枝，克制的电影绘画质感，保留可读的文字留白，无人物、无文字。原有插画、音乐和影片未替换。

工具图标取自 Lucide，许可见 `vendor/LICENSE-lucide`。

## 回归测试

需要 Node.js、Playwright 和可用的 Chromium 系浏览器：

```powershell
npm install --prefix tests --no-save --package-lock=false playwright
npx --prefix tests playwright install chromium
node tests/reader.cjs
```

先在另一个终端启动上述本地服务器。可用 `FHJJ_TEST_URL` 指定地址、`FHJJ_BROWSER` 指定浏览器可执行文件、`FHJJ_QA_DIR` 指定截图目录；默认输出位于被 Git 忽略的 `tests/output/`。

覆盖全部阅读帧、真实触摸事件、滚轮惯性、答题防重、音视频失败、拾取顺序、结尾触感时机、本地书评和草稿、旧进度、存储受限、图片失败、减少动态效果、离线启动，以及 320/360/390/430 像素宽手机、横屏和桌面布局。测试中的马达由记录调用参数的桩代替，不代表真机触感强度测试。
